## Project Overview
This project implements **Portfolio Theory**  to solve a supply chain optimization problem. By treating two suppliers as investment assets, we determine the optimal purchasing mix that minimizes price variance (risk) while maintaining competitive costs.

### **Key Objective:**
Find the optimal allocation between two suppliers that achieves the **minimum possible price volatility** using mathematical optimization techniques.


## Methodology
### **Portfolio Theory Applied to Supply Chain**
I treat each supplier as a "financial asset" with:
- **Return** = Expected cost savings 
- **Risk** = Price variance


## Results & Findings
